# Анализ отзывов клиентов компании по продаже мебели

## Цель проекта

Определить ключевые потребности и болевые точки клиентов компании по продаже мебели на основе анализа текстовых отзывов.

## Описание проекта

Проведён анализ отзывов по качеству мебели, сервису, доставке, возвратам, тональности и типам мебели.

## Задачи проекта

- очистка и подготовка данных;
- анализ оценок и тональности;
- анализ качества, сервиса и доставки;
- анализ возвратов и претензий;
- сравнение мягкой и корпусной мебели;
- сравнение компаний;
- проверка пяти гипотез;
- подготовка BI-монитора в Yandex DataLens.

## Проверяемые гипотезы

1. Негативные отзывы чаще связаны с сервисом, чем с качеством мебели.
2. Быстрая доставка повышает среднюю оценку.
3. Несоответствие описанию — наиболее частая причина возвратов и претензий.
4. Покупатели мягкой мебели оставляют более длинные и эмоциональные отзывы.
5. Чем выше цена товара, тем подробнее отзыв.

## Основные результаты

- H1 проверена на негативных отзывах по разметке сервиса и качества.
- H2 подтверждена в рамках текстового прокси быстрой/проблемной доставки.
- H3 не подтверждена: при проверке причин внутри отзывов с возвратом/претензией несоответствие описанию не является лидирующей категорией.
- H4 не подтверждена: корпусные отзывы в текущей выборке в среднем длиннее.
- H5 невозможно проверить без числовой цены товара и связи отзыва с конкретным заказом.

## Основные файлы

`reviews_yandex_1.xlsx` — единый входной файл с исходными полями: компания, оценка, дата и текст отзыва.

`analysis_reviews.py` — единый воспроизводимый скрипт очистки, нормализации текста, категоризации и проверки гипотез.

`отзывы_мебели_АНАЛИЗ_v2.xlsx` — единственный актуальный рассчитанный датасет, который используется для BI.

`аналитический_отчет_отзывы_мебель_ИСПРАВЛЕННЫЙ_2.docx` — актуальный аналитический отчёт.

`gpt_validation_prompt.md` — схема разметки для YandexGPT.

`requirements.txt` — зависимости проекта.

## Как запустить

```bash
pip install -r requirements.txt
python analysis_reviews.py
```

Вход: `reviews_yandex_1.xlsx`.

Выход: `отзывы_мебели_АНАЛИЗ_v2.xlsx` и папка `outputs/`.

### YandexGPT

Для запуска LLM-валидации задайте переменные окружения:

```text
YANDEX_GPT_API_KEY=...
YANDEX_CLOUD_FOLDER_ID=...
RUN_GPT=1
```

Ключи и токены в репозиторий не загружаются.

При запуске YandexGPT размечает детерминированную выборку отзывов, а результат сохраняется в `outputs/gpt_validation_sample.csv`. Основные числовые проверки гипотез остаются воспроизводимыми и не подменяются ответами модели.

## Ограничения

- нет числовой цены конкретного товара;
- нет структурированных дат заказа и фактической доставки;
- текстовые категории могут пересекаться;
- H2 и H4 используют текстовые прокси;
- YandexGPT применяется как отдельный слой валидации выборки.
