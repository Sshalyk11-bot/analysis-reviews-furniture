# Анализ отзывов клиентов компании по продаже мебели

## Цель проекта

Определить ключевые потребности и болевые точки клиентов компании по продаже мебели на основе анализа текстовых отзывов.

## Описание проекта

Проведён анализ отзывов по качеству мебели, сервису, доставке, возвратам, тональности и типам мебели с использованием Python и YandexGPT.

## Задачи проекта

- очистка и подготовка данных;
- анализ оценок и тональности;
- анализ качества, сервиса и доставки;
- анализ возвратов и претензий;
- сравнение мягкой и корпусной мебели;
- сравнение компаний;
- проверка пяти гипотез;
- дополнительная проверка разметки с помощью YandexGPT;
- подготовка BI-монитора в Yandex DataLens.

## Проверяемые гипотезы

1. Негативные отзывы чаще связаны с сервисом, чем с качеством мебели.
2. Быстрая доставка повышает среднюю оценку.
3. Несоответствие описанию — наиболее частая причина возвратов и претензий.
4. Покупатели мягкой мебели оставляют более длинные и эмоциональные отзывы.
5. Чем выше цена товара, тем подробнее отзыв.

## Основные результаты

- H1 проверена на негативных отзывах по категориям сервиса и качества.
- H2 подтверждена в рамках текстового анализа отзывов.
- H3 не подтверждена: несоответствие описанию не является основной причиной возвратов и претензий.
- H4 не подтверждена: отзывы о корпусной мебели в текущей выборке оказались длиннее.
- H5 невозможно проверить из-за отсутствия числовых данных о цене товара.
- YandexGPT использован для дополнительной проверки категорий причин жалоб и тональности на выборке отзывов.

## Основные файлы

`reviews_yandex_1.xlsx` — исходный датасет с отзывами.

`analysis_reviews.py` — основной скрипт очистки данных, обработки текста, категоризации, проверки гипотез и запуска YandexGPT.

`отзывы_мебели_Анализ_v3.xlsx` — актуальный обработанный датасет для дальнейшего анализа и BI.

`аналитический_отчет_отзывы_мебель_v3.docx` — актуальный аналитический отчёт.

`gpt_validation_prompt.md` — инструкция и схема разметки для YandexGPT.

`requirements.txt` — зависимости проекта.

`outputs/` — результаты дополнительных расчётов и проверки разметки YandexGPT.

pip install -r requirements.txt

RUN_GPT=1
