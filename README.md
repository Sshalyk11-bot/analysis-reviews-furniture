# Анализ отзывов клиентов компании по продаже мебели

## Цель проекта

Определить ключевые потребности и болевые точки клиентов компании по продаже мебели на основе анализа текстовых отзывов.

## Описание проекта

В проекте проведён анализ отзывов клиентов с целью выявления факторов, влияющих на удовлетворённость покупателей:

- качество мебели;
- сервис компании;
- скорость доставки;
- причины возвратов и претензий;
- особенности отзывов разных категорий товаров.

После очистки данных получено 2183 уникальных отзыва с текстом и оценкой.

## Задачи проекта

## Проверяемые гипотезы

В проекте проверены следующие гипотезы:

1. Негативные отзывы чаще связаны с уровнем сервиса, чем с качеством мебели.

2. Быстрая доставка повышает вероятность получения положительной оценки.

3. Основная причина возвратов — несоответствие товара описанию.

4. Покупатели мягкой мебели оставляют более длинные и эмоциональные отзывы.

5. Чем выше цена товара, тем подробнее отзыв клиента.

## Основные результаты

- Гипотеза о влиянии сервиса на негативные отзывы не подтвердилась.
- Быстрая доставка связана с более высокой средней оценкой отзывов.
- Несоответствие описанию не является основной причиной возвратов.
- Отзывы о корпусной мебели оказались длиннее отзывов о мягкой мебели.
- Влияние цены проверить невозможно из-за отсутствия данных о стоимости товаров.
