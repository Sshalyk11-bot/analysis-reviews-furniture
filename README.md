# Анализ отзывов клиентов компании по продаже мебели

## Цель проекта

Определить ключевые потребности и болевые точки клиентов компании по продаже мебели на основе анализа текстовых отзывов.

## Описание проекта

В проекте проведён анализ отзывов клиентов с целью выявления факторов, влияющих на удовлетворённость покупателей:

- качество мебели;
- сервис компании;
- скорость доставки;
- причины возвратов и претензий;
- тональность отзывов;
- особенности отзывов разных категорий товаров.

После очистки данных получен подготовленный набор отзывов для дальнейшего анализа.

## Задачи проекта

- очистка и подготовка данных;
- удаление дубликатов и некорректных записей;
- анализ распределения оценок;
- анализ качества мебели;
- анализ сервиса;
- анализ доставки;
- анализ возвратов и претензий;
- анализ тональности отзывов;
- анализ длины отзывов;
- сравнение мягкой и корпусной мебели;
- сравнение компаний;
- проверка пяти бизнес-гипотез;
- подготовка аналитического дашборда в Yandex DataLens.

## Проверяемые гипотезы

В проекте проверены следующие гипотезы:

1. Негативные отзывы чаще связаны с уровнем сервиса, чем с качеством мебели.
2. Быстрая доставка повышает среднюю оценку отзывов.
3. Возвраты и претензии связаны с несоответствием товара описанию.
4. Покупатели мягкой мебели оставляют более длинные отзывы.
5. Чем выше цена товара, тем подробнее отзыв клиента.

## Основные результаты

- Влияние сервиса и качества мебели проанализировано с помощью соответствующих признаков.
- Быстрая доставка связана с более высокой средней оценкой.
- Проведён анализ возвратов и претензий.
- Отдельно проанализирована длина отзывов о мягкой и корпусной мебели.
- Проведено сравнение средней оценки по компаниям.
- Гипотезу о влиянии цены проверить невозможно из-за отсутствия данных о стоимости товаров.
